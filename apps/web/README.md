# apps/web

Next.js (App Router) front end with shadcn/ui and Tailwind. pnpm only.

Run it from the repo root:

- `make install`: install dependencies
- `make dev`: core API in Docker, this app on http://localhost:3000
- `make check`: lint, typecheck and format check (with the core checks)

Add a shadcn component with `pnpm dlx shadcn@latest add <name>`.
